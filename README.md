# Weak RSA Parameters — Attacks on Real-Size Keys

A cryptography course project that generates **deliberately weak** 2048-bit RSA
keys and breaks them. Every attack recovers the private key (or plaintext) from
a weakness in *how the key was built*, not from small key size — so the demos
run on genuine real-size moduli, which earns more marks per the project brief.

> **Scope / ethics.** Every key attacked here is generated by this project's own
> `weakrsa.keygen` module. Nothing in this repo touches keys you do not own. This
> is cryptanalysis coursework, in the same spirit as Heninger et al.,
> *Mind your Ps and Qs* (USENIX Security 2012).

## The weaknesses and the attacks

| Attack | Weakness exploited | File | Typical time (2048-bit) |
|---|---|---|---|
| **Fermat factorisation** | `p` and `q` generated too close together | `weakrsa/attacks/fermat.py` | < 1 s |
| **Wiener's attack** | private exponent `d` chosen too small (`d < N^0.25`) | `weakrsa/attacks/wiener.py` | < 1 s |
| **Håstad broadcast** | `e = 3`, no padding, same message to ≥ e recipients | `weakrsa/attacks/hastad.py` | < 1 s |
| **Batch GCD** | low-entropy RNG makes two keys share a prime | `weakrsa/attacks/batch_gcd.py` | seconds for ~10k keys |

## Quick start

```bash
pip install -r requirements.txt
python demo.py          # generate weak keys and break each one, end to end
python benchmark.py     # find where each attack stops working (for the A-grade slides)
python -m pytest        # correctness tests
```

## Why each attack works (one line each, for Q&A)

- **Fermat.** If `p, q` are close, `N = p·q` is just below a perfect square.
  Search `a` upward from `⌈√N⌉` until `a² − N` is a square `b²`; then
  `p, q = a ± b`. Steps needed ≈ `(p − q)² / (4√N)`.
- **Wiener.** `d/k` is a convergent of the continued fraction of `e/N` whenever
  `d < N^0.25/3`. Test each convergent by solving for `φ(N)` and checking it
  factors `N`.
- **Håstad.** With `e = 3` and three ciphertexts of the *same* message under
  coprime moduli, CRT gives `m³ mod (N₁N₂N₃)`; since `m³ < N₁N₂N₃`, an integer
  cube root recovers `m`.
- **Batch GCD.** If two moduli share a prime, `gcd(Nᵢ, Nⱼ) ≠ 1` reveals it.
  A product/remainder tree does this across a whole key set far faster than all
  pairs.

## The "lift it to an A" part

`benchmark.py` measures the **boundary** of each weakness, which is the material
that turns a working demo into a graded investigation:

- Fermat: success vs. the prime gap `|p − q|`.
- Wiener: the `d < N^0.25` cliff.
- Batch GCD: how few bad RNG seeds it takes before keys start colliding.

Each attack module also documents the **fix** (the correct way to generate the
parameter), which is the natural closing slide.

## Layout

```
weakrsa/
  keygen.py            weak-key generators (one per weakness) + a safe baseline
  utils.py             integer sqrt/cuberoot, CRT, continued fractions
  attacks/
    fermat.py
    wiener.py
    hastad.py
    batch_gcd.py
demo.py                end-to-end: generate → attack → verify
benchmark.py           boundary experiments for the slides
tests/test_attacks.py
```

## Stretch goal (A+)

Coppersmith partial-key-exposure via lattice reduction (LLL) is the natural next
attack. It needs SageMath rather than plain Python, so it is left as a documented
extension in `weakrsa/attacks/__init__.py` rather than implemented here.
